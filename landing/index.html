Questions about running OptimoLMS

What does OptimoLMS run on?

One Go binary and a SQLite file. Migrations run at startup, so the schema moves with the release rather than in a separate step.

Which AI provider can OptimoLMS use?

Any OpenAI-compatible endpoint. A key is encrypted before it is stored and only replaces the old one after the provider answers.

How does sign-in security work?

Email, a password hashed with Argon2id, and a six-digit TOTP code. The session is an HttpOnly cookie and lasts 12 hours.

Can the assistant write into OptimoLMS on its own?

It calls the tools the interface uses: subject, week, lecture, assignment, quiz, flashcards, forum thread. Each call is checked against the caller's permissions first.

Where does OptimoLMS keep its permissions?

In the database, as named permissions per module, granted by role with per-user overrides. The answer is read on every request, never cached in the client.
